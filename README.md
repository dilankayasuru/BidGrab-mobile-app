# BidGrab Online Auction Platform - Flutter Mobile Application

> **Description**:  
> The BidGrab Mobile Application is a Flutter-based mobile app designed to provide users with a seamless and intuitive platform for participating in online auctions. This application serves as the mobile extension of the BidGrab Laravel web application, leveraging its API to deliver real-time auction functionality, user authentication, and data synchronization.

## Features

- User registration and login
- View live auctions
- Browse auctions by category
- Search auctions
- Place bids
- Create new auction
- Stripe checkout for payment
- Toggle between dark and light mode
- Deliver payed auctions
